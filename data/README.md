# Données réelles du client

Placez ici les fichiers de référence fournis :

- `Liste des Articles samedi 11-04-2026.xls`  (inventaire Excel)
- `ArticlePVPhoto 10 04 2026.pdf`            (catalogue prix + photos, 142 produits / 18 pages)

Ces fichiers sont exclus du dépôt Git (voir `.gitignore`) car ce sont des données
clients et des volumes binaires. Ils restent disponibles localement pour les
imports et l'extraction d'images.

## Usage

1. Copier les deux fichiers dans ce dossier.
2. Importer le fichier Excel depuis l'application : `Import / Export` → Import Excel.
3. Brancher / exécuter l'extraction du catalogue PDF pour peupler la bibliothèque d'images canoniques.
